# Zerox Tech Ltd

Website for Zerox Technology - Industrial Fluid & Water Tank Solutions.

## Project Structure
- `index.html`: Main entry point.
- `css/styles.css`: Stylesheet (using Tailwind CSS via CDN).
- `js/script.js`: Interactive logic.
- `assets/images/`: Directory for image assets.

## Setup
Simply open `index.html` in a web browser. No build step required as Tailwind is loaded via CDN.
